# InsulinGTAV

Generated by OrbisForge for the [OpenOrbis PS4 Toolchain](https://github.com/OpenOrbis/OpenOrbis-PS4-Toolchain).

Type: **GHPLUGIN** -> `build/InsulinGTAV.prx`

## Prerequisites

- `OO_PS4_TOOLCHAIN` environment variable set (in WSL, if building from Windows)
- clang + lld + cmake available on the build machine (WSL/Linux)

## Building

**Windows:** double-click `build.bat`, or `build.bat clean` to wipe the build directory.

**Linux / WSL (native):** `bash build.sh`, or `bash build.sh clean` (use `bash` rather than `./build.sh` since files written from Windows don't carry the executable bit).

## VS Code

Open this folder in VS Code and press **Ctrl+Shift+B** to build (`.vscode/tasks.json` runs
`build.bat`/`build.sh` for you). `.vscode/c_cpp_properties.json` points the C/C++ extension's
IntelliSense at the toolchain's headers via `${env:OO_PS4_TOOLCHAIN}`, which resolves
correctly under a **Remote-WSL** session or native Linux/WSL. If you're editing from a plain
Windows VS Code window (no Remote-WSL), IntelliSense needs `OO_PS4_TOOLCHAIN` set as a
*Windows* environment variable too, pointing at the toolchain's
`\\wsl.localhost\<distro>\...` path -- the build itself doesn't need this, only editor
autocomplete.
